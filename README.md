# Mirror Crack Generator

任意の画像上の衝撃点から割れ鏡風の亀裂を生成・合成する、ブラウザ完結型の画像加工ツール。

## 目的
イラストレーターが画像をアップロードし、衝撃点を選び、リアル／アニメ風のヒビを調整して、元画像の解像度のままPNG出力できるようにする。

## 技術スタック
- Vite + TypeScript（初期段階ではフレームワークなし）
- HTML / CSS / Canvas 2D API
- Vitest（アルゴリズムの単体テスト）
- GitHub + GitHub Pages

## 原則
- 画像はブラウザ内で処理し、サーバーへ送らない
- 亀裂生成、描画、UI、エクスポートを分離する
- 乱数シードで生成結果を再現可能にする
- 画面座標と元画像座標を分離する
- 段階的に実装し、各段階で動作確認する

詳しい仕様は REQUIREMENTS.md、構成は ARCHITECTURE.md、エージェント向け指示は AGENTS.md を参照。

## Phase 1 の実行方法

Node.js 20.19+ または 22.12+（検証環境: 24.19）を使用します。

```sh
npm ci
npm run dev -- --host 0.0.0.0
npm test
npm run build
npm run preview -- --host 0.0.0.0
```

画像を選択するかプレビュー領域に1枚ドロップし、画像上をクリックします。
元画像のピクセル座標で衝撃点を保持し、ウィンドウサイズが変わっても位置を維持します。
余白のクリックは無視し、別画像の読み込み時には衝撃点をリセットします。
画像読み込みに失敗した場合は前の画像を保持します。

現在は単一衝撃点の指定までに対応しています。亀裂生成、複数点の編集、PNG書き出しは未実装です。
最大画像サイズの実機検証とキーボードによる衝撃点指定は今後の課題です。
