# 鏡の破片領域の抽出 — 第1段階

`src/core/shardRegions.ts` にDOM・Canvas・乱数から独立した抽出器を追加。
既存の生成器・描画・UI・PNG出力からは呼び出さず、製品の見た目と画素を変更しない。
本段階は領域抽出だけで、実際の画像変形・UI接続は含めない。

## APIとデータ

```ts
extractShardRegions(size, segments, limits?)
// { ok: true, graph } または { ok: false, reason, message }
```

- `ShardSegment`: 座標と一意な元線分ID。複数衝撃点はIDを名前空間で分け、一括して渡す。
- `ShardVertex`: 抽出専用の共有頂点。元画像ピクセル座標で返す。
- `ShardEdge`: 端点ID、元線分IDの集合、左右の領域ID、辺の分類。
- `ShardRegion`: ID、外周、穴、穴を引いた面積・重心、境界辺ID。
- `ShardGraph`: 頂点・辺・領域。
- `ShardExtraction`: 成功／失敗の判別可能な結果。不完全なグラフは返さない。

入力は、実際に表示対象になっている線分を渡す。既存の経路referenceは未描画の区間も含むため直接使わない。
同一物理辺が複数の元線分に由来する場合は統合し、`sourceIds` に全て残す。
画像四辺は自動で追加する。画像外の線分は切り取り、ゼロ長・精度以下の辺は抽出から除く。

領域IDは正規化した境界座標列のハッシュ。同じ入力、並べ替え、線分の方向反転で同じ結果になる。
描画設定や変形設定を入力に持たず、乱数も消費しない。既存のシード再現性を変更しない。
ただし亀裂や分割頂点が変わった後のID永続性は保証しない。頂点IDは抽出結果内の識別子。
重心は凹領域や穴のある領域では領域外に来ることもあるため、将来の内部サンプル点としては使わない。

## アルゴリズム

1. 座標を画像長辺で正規化し、線分を画像矩形でクリップ。
2. x方向のsweep-and-pruneとy方向の包囲矩形で交差候補を限定。
3. X字交差・T字接触・端点接触を分割。同一直線上の部分／完全重複では相手端点も分割点にする。
4. 空間ハッシュで微小誤差内の頂点を共有し、重複した無向辺を統合。
5. 反復Tarjan法で橋を検出。橋は領域を分けない装飾辺として保持し、面の巡回から除く。
6. 半辺を頂点周囲の角度順に並べ、面を左側にたどる。正面積の閉路から有限領域を作る。
7. 負面積の閉路は左側のサンプル点を調べ、包含する最小の外周へ穴として帰属。画像外側は除外。
8. 左右の領域が異なる辺は破片境界、同じ辺は装飾。画像四辺は画像境界として別分類。
9. 面積合計、Euler特性、所属領域、有限値、ID重複を検証。

行き止まりを人工的に延長したり、中心保護円を架空の亀裂として追加したりしない。
分岐も実際に閉領域を分ける場合は境界になる。非連結閉路・入れ子の穴・頂点だけで接する閉路も扱う。
接触した外周には同じ頂点が複数回現れる場合がある。後段では単純多角形だと仮定せず、偶奇規則を使う。

## 安全予算・計算量

| 対象 | 既定の安全上限 |
| --- | ---: |
| 入力線分 | 10,000 |
| 分割後の無向辺 | 30,000 |
| 共有頂点 | 30,000 |
| 抽出領域 | 10,000 |
| 交差候補検査 | 2,000,000 |
| 分割点登録 | 120,000 |
| 包含判定の候補・辺検査 | 2,000,000 |

呼び出し側は上限を下げられるが、引き上げられない。
入力IDは一意・1〜256文字、座標は有限値、画像寸法は1〜8,192の整数を要求する。
入力異常は`invalid-input`、予算超過は`limit-exceeded`、精度・位相不整合は`invalid-geometry`。

候補検査は最悪O(N²)だが、実際に検査したペア数で打ち切る。全ペアを配列に保持しない。
分割後は辺数Eに対し、巡回・橋検出はO(V+E)、頂点周囲のソートは合計O(E log E)以下。
穴の帰属や装飾辺の所属判定は最悪二乗になるため、候補・輪郭辺の検査にも共通予算を適用する。
メモリは入力・分割点・頂点・辺・輪郭・元線分の由来に比例し、それぞれ生成時に制限する。
画像やピクセルバッファ、破片ごとのCanvasは一切確保しない。

精度は正規化座標で1e-10。これは元データを丸める処理ではなく、抽出用グラフの共有判定。
画像長辺8,192pxでは約0.00000082pxに相当する。近接特徴を統合することがあり、厳密な有理数幾何ではない。
精度限界に近い角度の交差や退化面は、安全に失敗として返す。
面積一致の許容誤差は画像面積の1e-8。これは全ての幾何誤差を検出する証明ではない。

## 今後の変形処理へ引き継ぐ方針

- 256個は抽出上限ではなく、将来の変形対象数の目安。**面積の大きい破片を優先し、小さい破片は元画像のまま残す**。
- 保護領域と重なる破片は、初期実装では**その破片全体の変形を無効化**する。円境界だけで画像を切り替えない。
- 上記の選択・円と領域の重なり判定・画像変形は本段階では未実装。穴や接触も含めた重なり判定を後段で追加する。
- 複数衝撃点の保護領域は合算して扱う方針。どれかと重なる破片は保護する。
- 抽出失敗時は従来表示へ戻す。今回の抽出器は失敗理由を返すだけで、製品描画へのフォールバック接続も後段。
- 弱い亀裂を境界候補に含める判定は呼び出し側の責務。現段階は受け取った全可視線分の幾何で分類する。
