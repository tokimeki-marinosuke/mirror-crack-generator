# 映りと選択点の調整：65%を旧最大にする

これは65%基準を導入した時点の記録。現在の通常UIは承認済み初期値を中央50に置くため、操作位置は [中央基準の調整](CENTERED_CONTROLS.md) を参照。

材質に続いて、映りと選択点の強度を拡張した。プリセットのモデル設定は変更せず、初期の見た目を維持したまま上側の調整余地を増やす。

| 項目 | 旧最大に相当する新しい操作 | 新しい最大 |
| --- | --- | --- |
| 映りのずれ・回転・明暗差・隙間 | 各65% | 旧最大の約1.54倍 |
| 不規則性・分岐 | 65% | 旧係数の約1.54倍まで |
| 蜘蛛の巣密度 | 65% | 基本接続段数は最大8→12（省略・長さにより実際の接続数は変化） |
| 衝撃の強さ | 65% | さらに長さ・不規則性を強める。50%の標準位置は維持 |
| 主要亀裂数 | 24本＝つまみ位置約65% | 35本 |
| 長さ | 150%＝つまみ位置約65% | 225%（画像短辺基準） |
| 黒い亀裂の太さ | 6px基準＝つまみ位置約65% | 9px基準（線種・経路による変調は維持） |

数・長さ・黒線幅の表示は、それぞれ本数・基準長比・pxのまま。表示値そのものを65%へ改名してはいない。

**中心半径・中心密度・不透明度・黒線の濃さは従来どおり。** 中心密度0は保護、100は最大破砕、不透明度100は完全不透明を意味する。65で飽和させて残りの範囲を無意味にしたり、不透明度を100%以上へ増幅したりしない。シード・光源角度も変更しない。

## 実装と互換性

- `core/effectRanges.ts`：65%と旧最大の対応、衝撃マクロの連続した順逆変換、拡張上限を共通化。
- `ui/editor.ts`：不規則性と蜘蛛の巣のUI強度を実効値へ変換。モデルに保持する旧設定はそのままで、表示だけを新スケールへ変換する。例えば旧プリセットの不規則性75は新UIでは約49%だが、適用されるモデル値は75で初期形状は同じ。
- 衝撃マクロはUI0〜50を従来どおりにし、50〜65で旧50〜100へ、65〜100で旧100を超える実効値へ連続変換する。旧最大で飽和していた長さ・不規則性の上限も連続的に広げ、65%直後の値の跳ねを避ける。プリセット基準と個別指定優先は維持する。
- `generateCracks.ts`：範囲検証だけを拡張。角度、接続、分岐、中心、乱数の生成式は変更していない。既存の0〜100係数・24本以内などの同一モデル入力は従来と同じ亀裂になる。
- `editorState.ts` / `fractureSettings.ts`：線幅・マクロ・個別指定の新上限を検証。高いマクロでは上限を拡張するが、旧マクロ100以下での従来の提案値は保つ。中心・線幅・手動指定をマクロが上書きすることはない。
- `ShardImageState` / `createShardTransformPlan`：範囲モードを追加。製品の `EditorState.shards` はexpanded。独立した既存APIは既定でlegacyなので、従来の呼び出し側の100の意味を維持する。

映りは強度だけを変え、閉領域やシード由来の変形方向は再生成しない。新65の実効値を旧100へ変換して同じ計算順を使い、旧100の変形計画と全データが一致する。旧12pxの移動上限は新最大で約18.5px、旧1°の回転上限は約1.54°、旧最大8%の明暗変化は約12.3%相当になる（小片・画像寸法による、より小さい上限も維持）。

中心保護と重なる破片全体、256個を超える小片は従来どおり据え置く。形状の上限を増やしても線分上限5000・抽出の安全予算は増やさない。密度を極端に上げた場合、上限によって細部を省いたり、抽出失敗時に元画像/簡易描画へ復帰したりすることがある。

旧破断面の面・三角形を通常描画から除外する方針、黒線幅と反射幅の独立性、合成/透明PNGの区別は維持する。

## 確認方法

```sh
npm test
npm run build
npm run dev
```

通常画面から映り4項目と不規則性・蜘蛛の巣を65→100へ上げて比較する。衝撃の強さは50→65→100で確認する。
本数・長さ・黒線幅は表示の実数値を確認する。選択点の最大値や中心保護を確認した[操作画面](expanded-effect-controls.png)も参照。

Playwright/Chromiumが利用できる環境では以下を実行（必要ならNODE_PATHで既存のPlaywrightを指定）。

```sh
node tests/editor-ui.cjs
node tests/expanded-effect-ui.cjs
```

`effectRanges.test.ts` は映り65と旧100の変形計画完全一致、100の増幅、保護、抽出キャッシュ、強い生成設定の再現性/有限性/線分上限、マクロの旧最大一致と個別指定優先を検証する。
`expanded-effect.browser.ts` は実際の合成PNGで新65と旧100が一致し、新100で変化し、亀裂のみPNGが変化しないことを確認する。
`editor-ui.cjs` は最新の通常UIを対象に、実数上限、全プリセット、中心0/半径80/不透明度100などの端点、点ごとの独立設定、両PNG保存を検証する。

## 残る制約

濃さ・不透明度の上限は物理的な100%のまま。旧最大を超える不規則性・接続数や黒線幅は、作品によって強すぎる場合がある。65付近から調整する。Safari/Firefox、低メモリ端末の実機評価は引き続き未完了。
