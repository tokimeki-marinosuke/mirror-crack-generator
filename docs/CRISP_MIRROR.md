# 黒い亀裂と独立反射による描画の更新

旧シネマティックは細く薄く、旧破断面幅を上げると大きな黒帯・三角形が発生した。今回は「旧材質最大・破断面幅0」を比較基準に、通常描画を新しい黒線と局所反射へ切り替えた。

## 見た目と操作

[同一画像・シードの比較](crisp-mirror-comparison.png)：左上が旧デフォルト、右上が旧材質最大、左下が新デフォルト、右下が新最大。外部作品は使わず、顔・文字を含む自作SVG確認素材を比較ページ内で生成している。

旧デフォルトより黒い亀裂の輪郭が明確になり、主要亀裂の一部に白い反射が見える。大きな突起を追加せず、顔や文字は見える状態を維持する。見た目の最終評価は作品に依存するため、この比較と利用者の実画像で確認する。

- 「線幅」は「黒い亀裂の太さ」に整理。既存のlineWidth 0.5〜6pxを幅の基準として再利用する。線種・経路位置・Realistic/Animeにより実際の描画幅は変わる。
- 新しい「反射幅」は0〜100%、画像全体で共通。黒線の輪郭に追従するが、黒線幅に連動して太くならない。0では白い反射線を描かない。
- 各点の暗部設定を「黒い亀裂の濃さ」として使う。
- 旧破断面幅・旧欠け密度・従来の縁反射は通常UIから削除。既存の割れ方プリセットに旧値があっても通常描画では参照しない。
- 材質無効・全効果0は黒い亀裂だけの表示。以前の黒帯・三角形に戻る操作にはしない。

| 材質プリセット | 厚み | エッジ反射 | 反射幅 | 内部反射 | 微細ディテール |
| --- | ---: | ---: | ---: | ---: | ---: |
| シネマティック | 65 | 68 | 65 | 60 | 22 |
| リアル | 28 | 40 | 35 | 25 | 8 |
| ドラマティック | 90 | 92 | 85 | 75 | 48 |

光源は全て左上225°。適用後も自由に調整でき、位置・シード・中心保護・形状・既存の映像変形設定は変更しない。

## 責務と互換性

- `core/cleanCracks.ts`：純粋関数で、既存の中心線サンプルから滑らかな幅の黒線輪郭・半透明断面・反射縁を計算する。主要亀裂は太く、接続・分岐は細くする。断面と強い反射は主要亀裂だけに付ける。
- `render/renderCleanCracks.ts`：黒線 → 断面 → 選択的な反射 → 短い微細な光の順で描画。画像境界と既存の中心領域でクリップする。微細ディテールの三角形は塗らず、固定候補の短い細線だけを使う。
- `GlassMaterialState`：`appearance='clean'` を製品のEditorStateから指定する。旧破断面データを除いて輪郭を準備し、黒線幅・反射幅・材質変更で中心線/分割/候補を再生成しない。
- `renderGlassScene`：cleanフレームは材質無効・幾何失敗時も新しい描画へ渡す。失敗時の簡易黒線描画も旧面を使わない。
- `renderPreview` と `exportPng`：同じcleanフレームを受け取り描画を共有する。内部反射は合成のみ、断面・反射は透明レイヤーにも残す。

低レベルの旧描画API・旧破断面生成・設定フィールドは保持する。独立した `GlassMaterialState(size)` の既定はlegacyで、以前の開発比較を継続できる。材質フレーム省略のAPIも従来描画のまま。通常アプリは必ずcleanフレームを渡すため、旧データや旧プリセットから面・突起は復活しない。

反射幅を持たない既存の材質設定は65を補う。反射幅だけを変更しても材質効果を有効化しない。旧破断面の設定を互換APIで編集すると従来データを生成できるが、通常描画は使用しない。

## 強度の拡張

強度を `値/65` で基準化する。見た目全体の完全な画素一致を意味せず、65付近が旧最大の効果量の目安。

- 厚み：65を超えると断面の張り出しを広げる。濃度は基準量で抑え、黒帯化を避ける。
- エッジ反射：65を超えると経路に沿った明るい区間と光源側の応答範囲を広げる。光源の反対側まで一様に白くしない。
- 反射幅：黒線や断面位置を変えず、白い反射線の太さだけを変える。
- 内部反射：65付近で旧最大の弱い勾配に達し、それ以上は勾配の明暗が及ぶ範囲を広げる。source-atopによる元画像のアルファ保持と破片全体の中心保護を維持する。
- 微細ディテール：安定した少数候補の濃さと短い反射線の長さを変える。三角形の面は描かず、候補の数や位置も増減させない。

描画用輪郭は既存の上限付きサンプルから計算し、追加の全解像度Canvasは作らない。分割抽出・画像変形には変更を加えていない。

## 検証・比較の実行

```sh
npm test
npm run build
npm run dev
```

`/mirror-crack-generator/tests/crisp-mirror.html` で同じ画像・シード・中心密度・黒線幅を使い比較する。明るい/暗い/透過画像も選択可能。新最大の反射幅は100%、それ以外の新描画の反射幅は比較ページの値を使う。

Playwright / Chromiumが使える環境で以下を実行（必要なら既存のPlaywrightをNODE_PATHで指定）。

```sh
node tests/crisp-mirror-ui.cjs
node tests/glass-controls-ui.cjs
GLASS_QUICK=1 node tests/glass-material-ui.cjs
```

`crisp-rendering.browser.ts` は旧幅/欠け100のままで12条件の明暗/透明素材・複数点・中心密度を検証する。通常・材質無効・幾何失敗時の旧面無視、元寸法、合成/透明PNG一致、中心保護を確認する。結果は [crisp-mirror-results.json](crisp-mirror-results.json)。描画時間は環境依存の単発測定として記録し、CIの時間制限には使わない。

## 残課題

Safari/Firefox・低メモリ端末の実機確認と、利用者の作品での初期値評価は未完了。新旧で画素の見た目は意図的に変わる。旧描画と一致することを新通常描画の合否条件にはせず、中心線・分割・乱数の不変性と各出力の整合性を確認する。

## 今回の結果

- `npm test`：226件成功（新規10件）。同時負荷で既存の重いテストが一度5秒を超過したが、単独での再実行は通常の設定のまま全成功。テストの時間上限や検証内容は緩めていない。
- `npm run build`：型チェック・本番ビルド成功。
- 新しい描画の12条件・102検証成功。旧面の無視、元寸法、実PNG一致、中心保護、反射幅0、無効/失敗時の安全な描画を確認。
- 既存の材質検証13項目・製品描画11項目、トポロジー8件・PNG17件成功。
- 本番ビルドで材質UI（独立した黒線幅と反射幅を含む）・既存の画像変形UIを確認し、両PNG保存も成功。
- 自作比較素材を目視し、旧デフォルトより主要輪郭が明確になり、顔・文字の判読を維持できることを確認。
- 別の800×500参照場面では、亀裂レイヤーのアルファが32/255を超える画素が約1.8%→約3.1%。これは占有面積の目安で、作品の美しさや顔の視認性を自動判定する指標ではない。
- 同環境・同じ経路で5フレーム描画＋読み戻しの中央値は旧材質最大93.0ms、新シネマティック93.8ms。分割・PNG圧縮を含まず、実行環境に依存する一度の測定。
