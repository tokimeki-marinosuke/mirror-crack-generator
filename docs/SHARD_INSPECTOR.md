# 破片領域の可視化 — 第2段階

開発用の `tests/shards.html` に抽出領域・穴・辺分類・中心保護の診断表示を追加した。
既存の亀裂生成、描画、状態、製品UI、PNG出力は変更していない。
画像変形は未実装であり、色分け／斜線／選択表示はこの検証ページだけの機能。

## 開き方

```sh
npm ci
npm run dev
```

表示されたローカルURLの `/mirror-crack-generator/tests/shards.html` を開く。
開発専用であり、通常の `npm run build` やGitHub Pagesの公開画面には含まれない。
素材は既存の自作サンプル `docs/samples/light.png`。画像を外部へ送信しない。

## 表示と操作

- 左：元画像＋入力亀裂。生成ケースは既存の `renderCracks` を使用する。
- 右：抽出した全領域をID由来の安定した色で描画する。外周と穴は `evenodd` で扱う。
- 橙色の実線：破片境界。青い破線：領域を分けない装飾亀裂。灰色：画像四辺。
- 右のCanvasまたは一覧をクリックするとID・面積・面積比・穴数・境界辺数・保護対象を表示。
- 面積順の一覧は最大500件。Canvasでは全領域を描画・選択できる。
- 表示切替・選択では抽出結果とPath2Dを再利用。ケース・シード・中心密度の変更時だけ再抽出する。
- シードと中心密度は生成ケースだけで有効。既知図形には適用しない。

中心保護は、円だけを切り替えるマスクではなく、円と重なる**破片全体**を元画像＋斜線で表示する。
破線の円は診断用ガイドであり、実際の亀裂や新しい境界ではない。
重なり判定は円と辺の接触、円が破片内、破片が円内を扱い、穴の中だけにある円を除外する。
複数衝撃点では、いずれかの保護円と重なる破片を対象とする。
これは検証用の判定で、製品の画像変形や保護処理にはまだ接続していない。

## 7つの確認ケース

| ケース | 確認する内容 |
| --- | --- |
| 生成亀裂・1衝撃点 | シード・中心密度と保護領域 |
| 生成亀裂・複数衝撃点 | 名前空間を分けた線分の統合と複数の保護円 |
| 入れ子の穴 | 3領域・穴2・装飾2辺。固定保護円が穴付き外側領域を誤って保護しない |
| T字・X字・行き止まり | 分割境界と装飾の区別 |
| 289領域 | 256超でも抽出・可視化を停止しない |
| 安全予算超過 | 失敗理由、空の選択状態、元画像＋亀裂への復帰 |
| 精度限界 | 幾何エラーでも同様に復帰し、次の正常ケースへ戻れる |

[生成亀裂の表示](shard-inspector-generated.png) / [穴と保護の表示](shard-inspector-holes.png) / [抽出失敗の表示](shard-inspector-fallback.png)

失敗時には以前の色分け・選択・一覧を破棄し、左のCanvasを右へそのままコピーする。
右側が古い抽出結果のまま残らないことと、復帰表示の画素一致をブラウザで検証する。

## 検証

```sh
npm test
npm run build
```

Playwright・Chromiumが利用できる環境では、別ターミナルで製品サーバーを起動してから以下を実行する。
アプリの依存パッケージは追加していない。必要なら既存のPlaywrightに対して `NODE_PATH` を指定する。

```sh
CHROMIUM_PATH=/usr/bin/chromium node tests/shards-ui.cjs
```

`SHARDS_URL` で接続URLを変更できる。シナリオ7種、色分け、穴、クリック選択、保護、289領域、
再抽出の抑制、失敗時の画素一致と回復、シード、狭い画面でのクリック位置を検証する。
`tests/shardScenarios.test.ts` は図形ケースと保護重なりの純粋な単体テスト。
既存の `tests/topology.html` の8件、`tests/export.html` の13件も維持する。

## 残る作業

次の第3段階で、シード付きの画像のずれ・回転を開発ページで実装できる。
現段階では256件の変形対象選択、変形行列、画像変形、製品UIへの接続、合成PNGへの適用は行っていない。
保護判定は境界への接触も対象とする保守的な診断で、描画のアンチエイリアス余白などの調整は後段で行う。

実施結果：単体153件（新規4件）、開発ページの7ケースと操作テスト、既存画素比較8件・PNG13件、ビルドが成功。
既存の大量生成テストが一度5秒制限を超えたが、再実行では約3.2秒で終了して全件成功した。
