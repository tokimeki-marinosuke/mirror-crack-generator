# 破断面表現 — 第2段階

第1段階の経路・共有頂点・正規化弧長を使い、主要亀裂の破断面を追加する。
この段階は細長い暗い隙間と片側の反射までを対象とする。

## 処理の分離

1. `generateCracks`: 従来の中心線・接続情報を生成。乱数の消費や座標計算は変更しない。
2. `generateFractureSurface`: 元画像サイズ・パターン・破断面幅から多角形と反射縁を生成する純粋関数。
3. `renderCracks` / `renderFractureSurface`: 同一の中心線と破断面を、プレビュー・合成PNG・透過PNGで描画する。

元画像の画素を消去せず、亀裂レイヤーを `source-over` で重ねる。
透明PNGにも暗部と反射を含める。暗部・反射を0にしたとき、破断面は元画像を消さない。
元画像解像度を保ち、編集マーカーは引き続きPNGへ含めない。

## 多角形と反射縁

- 対象はトポロジーの `radial` 経路の可視edgeだけ。網目・分岐は既存の細線表示を維持。
- 同一経路・領域・強度で連続するedgeをまとめ、予算やクリッピングで切れた非表示区間を勝手につながない。
- 幅プロファイルは経路ID・シード・固定した経路位置から求める。中心線の乱数状態には触れない。
- 基準経路の頂点と固定のサンプル位置を使用し、接続点追加による細分化で幅模様を変えない。
- 経路の始終点を先細りにし、滑らかな不規則幅と左右非対称な広がりを与える。
- 細線の線幅とは独立。100%で短辺の3%を最大基準幅とし、上限24元画像px。
- 反射側は経路の向きから一貫して選ぶ。白い反射縁の太さは破断面幅から計算し、細線幅に依存しない。
- 中心密度0の保護円には太い断面・反射も入れない。中心／外側はそれぞれ現行のマスクでクリップする。
- 多角形の生データは画像・中心境界をはみ出す場合がある。描画時の領域制約も含めて使用すること。

中心線は今回も変更しない。画像を実際に切り抜くマスク、鋭い欠けの追加、閉じた破片領域、
破片移動、衝撃マクロのUI、新しいプリセットは後段で実装する。

## 設定とキャッシュ

`Impact.surface` に `widthPercent`・`darkness`・将来用 `chipDensity` を保持し、
`Impact.fracture` に生成済みの面を保持する。旧形式の手製Impactも許容するため両方とも省略可能。
`chipDensity` は現段階では使用しない。

`EditorState.updateSurface({ widthPercent, darkness })` で選択点だけを更新できる。

| 変更 | 再利用／再生成 |
| --- | --- |
| 破断面幅 | 中心線を再利用し、破断面だけ再生成 |
| 暗部の強さ | 中心線・破断面を再利用し、描画だけ変更 |
| 反射・不透明度・細線幅 | 中心線・破断面を再利用 |
| シード・位置・生成パラメータ | 中心線と、その点の破断面を更新 |
| プリセット | 従来の生成・細線設定を更新し、破断面幅・暗部はその点の設定を保持 |

既定の破断面幅は0で、従来の画面・PNGと全画素が一致する。
トポロジーのない旧形式パターンでは、破断面を生成せず従来の細線だけを描く。

第4段階の編集UIに先行しないため、製品画面には新しいスライダーを追加していない。
開発用ページで効果を確認できる。衝撃マクロもまだ製品画面へ接続しない。

## 検証・比較

```sh
npm test
npm run build
npm run dev
```

開発サーバーの `/mirror-crack-generator/tests/fracture.html` を開く。
同じ画像・シード42・中心密度0の左右比較で、幅・暗部・反射を調整できる。
[比較画像](fracture-stage2.png)は破断面幅80%、暗部85%、反射80%で撮影。

`/mirror-crack-generator/tests/topology.html` は幅0の公開版との画素一致を検証する。
`/mirror-crack-generator/tests/export.html` は従来のPNGテストに加え、
破断面の中心保護、透明PNGの暗部と反射、幅0への復帰、不透明度0、元画像のRGBA保持を検証する。

各経路は有限個の基準点と固定32区間でサンプリングし、多角形は最大1,024面・32,768頂点に制限する。
この段階では全交差の除去や多角形の統合は行わない。異なる経路が重なる部分では
暗部が濃くなる場合があり、接合部の高度な調整・欠けの表現は今後の課題。

第3段階では同じ帯を維持して欠けを追加した。[欠けと中心破砕の設計](FRACTURE_CHIPS.md)を参照。
