# ガラス材質・第4段階：本番プレビューとPNGへの接続

この文書は第4段階時点の記録。現在の通常UI・初期値・全0の挙動は [黒線と独立反射の更新](CRISP_MIRROR.md) を参照。旧破断面幅・欠け密度は通常UIから削除済み。

第1〜3段階の独立した材質データ・描画を本番画面へ接続した。画像ごとに共通光源と材質設定を持ち、既存の衝撃点設定・亀裂形状・画像変形とは独立させる。

## 操作と初期値

画像を読み込むとシネマティックが初期設定になる。材質は衝撃点を追加すると確認できる。

| プリセット | 厚み | エッジ反射 | 内部反射 | 微細ディテール | 光源 |
| --- | ---: | ---: | ---: | ---: | ---: |
| シネマティック | 32% | 60% | 25% | 15% | 225° |
| リアル | 12% | 30% | 12% | 5% | 225° |
| ドラマティック | 65% | 90% | 45% | 55% | 225° |

プリセットは設定値の組み合わせで、適用後の操作制限はない。手動編集すると表示はカスタムに変わる。プリセットの再選択は材質設定だけを初期化する。

「材質効果を有効にする」を外すと設定値を保持して従来表示に戻る。「材質効果を0に戻す」は全効果0・無効へ戻す。光源0°は右、90°は下、225°は左上。画像を変更するとシネマティックに初期化する。

Realistic / Animeと既存の割れ方プリセットは、従来どおり各衝撃点の形状・線描画を担当する。画像全体の材質設定を上書きしない。衝撃マクロも材質設定を書き換えない。

新しいエッジ反射が正の場合は従来の均一な白ハイライトを置き換える。0なら「従来の縁反射」が有効になる。二重に白線を描かない。ガラスの厚みと既存の隙間幅・線幅は独立。材質プリセットは画像のずれ・回転・明暗差・隙間を変更しない。

## 共通パイプライン

`EditorState.glass` が `GlassMaterialState` を保持する。低レベルの材質初期値は引き続き無効・全0で、EditorState生成時だけシネマティックを適用する。既存の開発比較やAPIの互換性を維持する。

`renderPreview` と `exportPng` は任意の追加引数として同じ `GlassMaterialFrame` を受け取り、`renderGlassScene` を共有する。フレームを省略した既存の呼び出しは従来描画のまま。無効時のプレビューは既存の縮小画像描画経路も保持する。編集マーカーはプレビューにだけ後から描く。

- 合成PNG：既存の画像変形 → 内部反射 → 亀裂・断面・局所反射・微細欠け。
- 亀裂のみPNG：背景と内部反射は描かず、亀裂の暗部・断面・局所反射・微細欠けを透明背景へ描く。
- 元画像寸法を維持し、元画像のファイルや画素を直接変更しない。

材質設定は画像全体で共有し、点の選択・追加・削除でも維持する。中心保護は各衝撃点の既存クリップと、内部反射に対する破片全体の保護を使う。内部反射の対象は最大256片、大きい片を優先する。

## 操作負荷と安全性

既存のRAFキューに材質スライダーも接続し、同じフレーム内の操作をまとめる。PNG保存直前には未反映の入力を同期する。保存はその時点の画像・衝撃点・材質フレームを使う。

材質の強度・光源・プリセットでは中心線・破断面・平面分割を再生成しない。輪郭と内部材質計画を別キャッシュで保持し、既存の画像変形が有効なら同じ抽出グラフを再利用する。

輪郭データを安全に準備できない場合は従来描画へ戻す。内部反射だけの抽出失敗なら、その効果だけを省略する。画面に状態を表示し、PNGも同じ条件で描く。

## 確認方法

```sh
npm ci
npm run dev
npm test
npm run build
```

通常の `/mirror-crack-generator/` を開く。[操作画面](glass-material-controls.png)も参照。

Playwright / Chromiumが使える環境では、Vite起動後に以下を実行する。必要なら既存PlaywrightへのNODE_PATHを指定する。

```sh
node tests/glass-controls-ui.cjs
GLASS_QUICK=1 node tests/glass-material-ui.cjs
node tests/shard-composite-ui.cjs
```

`glass-controls-ui.cjs` は実画面から画像読み込み、3プリセット、5スライダー、無効化と復帰、全0、両PNG保存、保存直前入力、点間での共有、新画像初期化を確認する。
`glass-texture.browser.ts` の製品検証11項目は3プリセットの実PNGと共通描画、元解像度、プレビュー、全0時の従来PNG一致を確認する。

開発用の旧描画/新描画比較ページも引き続き利用できる。公開画面に診断線や比較UIは追加しない。

## 残る制約

厳密な反射・屈折、別の景色の映り込み、破片の落下は対象外。Safari/Firefox、最大解像度付近での体感性能、利用者のイラストを用いたプリセット調整は引き続き確認が必要。
