# 承認した見た目をつまみ中央50%にする

前回選ばれた初期値を「上限」にするのではなく、調整範囲の中央へ置いた。初期の実効値・描画・シードは変えていない。

## 操作上の区別

**つまみの位置は0〜100、横に表示する数値は実際の設定値。** 中央50にすると、29本・長さ192%・映り100%など、前回承認された設定になる。右へ動かすとさらに大きい値になる。例えば「映り100%」は今回のつまみ位置50であり、つまみ位置100は実効200%。位置と実効値の違いは説明文とaria-valuetextにも記載する。

実値を表示することで、不透明度85%・中心密度4%・半径7%の意味を曖昧にしない。中心密度0は保護、不透明度100は完全不透明のまま。

光源は方向なので225°を維持、シードは整数1のまま。初期値0の隙間は左端0に残す。負の隙間を作ったり、左半分が全く働かないつまみにしたりしない。

| 項目 | 中央50の実効値 | 右端100の実効値 |
| --- | ---: | ---: |
| 厚み | 65 | 130 |
| 反射幅 | 65 | 130 |
| エッジ反射 | 68 | 136 |
| 内部反射 | 60 | 120 |
| 微細ディテール | 22 | 100 |
| 映りのずれ・回転・明暗差 | 各100 | 各200 |
| 主要亀裂数 | 29本 | 45本 |
| 長さ | 192% | 300% |
| 不規則性 | 74%相当 | 117%相当 |
| 蜘蛛の巣 | 97%相当 | 123.5%相当 |
| 中心半径 | 7% | 80% |
| 中心密度 | 4% | 100% |
| 黒線幅 | 1px基準 | 9px基準 |
| 不透明度 | 85% | 100% |
| 黒線の濃さ | 60% | 100% |

衝撃マクロは元から50が標準なので、その位置と上側の調整を維持する。本数は整数に丸める。通常の範囲は中央までと中央以降を線形につなぎ、中央で実効値が飛ばないようにする。

[操作画面](centered-controls.png)。初期値の実数表示は以前のままだが、つまみが中央に移動している。

## 実装と互換性

`state/controlScale.ts` が各項目の最小・基準・最大と順逆変換を一元管理する。UIを更新してもモデル値を勝手に再量子化せず、位置50では基準値を丸めずに厳密に返す。元の初期形状やPNGを変えないための措置。

`applicationDefaults.ts` は実効値を従来のまま保持する。通常アプリだけwide範囲を有効にし、材質・映りに100超の実効強度を許可する。低レベルの既存APIは0〜100の検証とlegacy/expandedの挙動を維持する。

`effectRanges.ts` の形状上限は45本・長さ300・不規則性180・蜘蛛の巣190へ拡張。古い入力に対する乱数と生成式は変更しない。線分5000、破片抽出の安全予算、最大256片への映り適用、中心保護は維持する。極端な組み合わせでは安全上限による簡易描画・抽出フォールバックがある。

材質の上限拡張は濃度を際限なく増やす処理ではない。既存の断面・反射区間・勾配の広がりを強め、色のアルファと元画像の透過を保つ。旧破断面の大きな黒帯・三角形は引き続き通常描画に使わない。

## 確認

```sh
npm test
npm run build
npm run dev
# Playwright/Chromiumがある環境で別ターミナルから（必要ならNODE_PATHを設定）
node tests/centered-controls-ui.cjs
node tests/application-defaults-ui.cjs
node tests/expanded-effect-ui.cjs
```

- 単体検証：基準位置の厳密一致、上下の範囲、連続性・可逆性、保護/不透明度の端点、低レベルAPIの範囲維持。
- 画面検証：各初期つまみ位置50と実効値、右側での増幅、50へ戻した際の全画素一致、プリセット、両PNG、保存前入力の反映、点間での共有。
- 実PNG検証：従来の承認済み初期値と中央50の合成/透明PNGが一致し、上側の映りは従来上限を超えて変化することを確認する。

旧 `tests/editor-ui.cjs` と `glass-controls-ui.cjs` は現在の校正済み操作テストを実行する入口として残す。

## 今回の結果

- `npm test`：246件成功、`npm run build`：型チェック・本番ビルド成功。

- 既存の映りUI、トポロジー8件・PNG17件も成功。低レベルの互換検証と描画予算は維持。
